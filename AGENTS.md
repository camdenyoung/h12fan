# H12Fan repository instructions

## Versioning

- Increment the patch (revision) number for every user-requested change set, including small fixes, wording, styling, and configuration changes. For example, the next change after v0.1.1 should be v0.1.2.
- Bump once per change set, not once per edited file or intermediate commit.
- Honour an explicitly requested version instead of calculating a different one.
- Update both the visible header version and its accessible label in `h12fan/static/index.html`. Preserve the existing small, muted version styling beside the app name.
- Include the version bump in the same commit as the change.
